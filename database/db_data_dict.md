# 賽馬數據庫數據字典 (Data Dictionary)

本數據庫主要用於存儲香港賽馬會 (HKJC) 的賽事紀錄、馬匹比賽結果與分段走位數據。

---

## 📋 資料表清單

1. [`races`](#1-races-賽事基本資料) - 賽事基本資料
2. [`race_results`](#2-race_results-賽果與馬匹成績) - 賽果與馬匹成績
3. [`race_sectionals`](#3-race_sectionals-分段時間與走位數據) - 分段時間與走位數據

---

## 1. `races` (賽事基本資料)

記錄每場賽事的日期、場地、班次、路程與跑道狀況等基本資訊。


| 欄位名稱 (Column)     | 資料型態 (Type) |  主鍵 (PK)  | 允許空值 (Null) | 說明 (Description) | 範例 / 備註                                    |
| :-------------------- | :-------------- | :---------: | :-------------: | :----------------- | :--------------------------------------------- |
| **`race_id`**         | `TEXT`          | Primary Key |       No       | 賽事唯一識別碼     | `2024-01-01_ST_1` (`{date}_{venue}_{race_no}`) |
| **`date`**            | `TEXT`          |      -      |       No       | 賽事日期           | `2024-01-01` (格式: YYYY-MM-DD)                |
| **`venue`**           | `TEXT`          |      -      |       No       | 賽事場地           | `ST` (沙田) / `HV` (跑馬地)                    |
| **`race_no`**         | `BIGINT`        |      -      |       No       | 場次               | `1`, `2`, `3` ...                              |
| **`race_class`**      | `TEXT`          |      -      |       Yes       | 賽事班次           | `1`, `2`, `3`, `4`, `5`, `G1`, `G2`, `G3`      |
| **`distance`**        | `FLOAT`         |      -      |       Yes       | 賽事途程 (米)      | `1200`, `1400`, `1600`, `2000`                 |
| **`track_condition`** | `TEXT`          |      -      |       Yes       | 場地狀況           | `好地`, `快地`, `黏地`, `濕慢地`               |
| **`track_texture`**   | `TEXT`          |      -      |       Yes       | 跑道材質           | `草地`, `泥地`                                 |
| **`track_type`**      | `TEXT`          |      -      |       Yes       | 賽道/跑道向        | `A`, `B`, `C+3`, `N/A` (泥地)                  |

---

## 2. `race_results` (賽果與馬匹成績)

記錄每場賽事中參賽馬匹的最終名次、騎練資訊、負重、賠率及完賽時間。


| 欄位名稱 (Column)     | 資料型態 (Type) |  外鍵 (FK)  | 允許空值 (Null) | 說明 (Description)       | 範例 / 備註                               |
| :-------------------- | :-------------- | :----------: | :-------------: | :----------------------- | :---------------------------------------- |
| **`race_id`**         | `TEXT`          | FK (`races`) |       No       | 對應賽事識別碼           | `2024-01-01_ST_1`                         |
| **`horse_id`**        | `TEXT`          |      -      |       Yes       | 馬匹烙號 / 專屬代號      | `E123`, `G045`                            |
| **`horse_name`**      | `TEXT`          |      -      |       No       | 馬匹名稱                 | `金槍六十`                                |
| **`placing`**         | `BIGINT`        |      -      |       Yes       | 最終名次                 | `1`, `2`, `3` ... (特別狀況如退出為 Null) |
| **`draw`**            | `BIGINT`        |      -      |       Yes       | 排位檔位                 | `1` ~ `14`                                |
| **`jockey`**          | `TEXT`          |      -      |       Yes       | 騎師名稱                 | `潘頓`, `何澤堯`                          |
| **`trainer`**         | `TEXT`          |      -      |       Yes       | 練馬師名稱               | `呂健威`, `告東尼`                        |
| **`actual_weight`**   | `FLOAT`         |      -      |       Yes       | 實際負重 (磅)            | `123.0`, `133.0`                          |
| **`declared_weight`** | `FLOAT`         |      -      |       Yes       | 報到體重 / 馬匹體重 (磅) | `1120.0`                                  |
| **`win_odds`**        | `FLOAT`         |      -      |       Yes       | 獨贏獨開賠率             | `2.5`, `15.0`                             |
| **`finish_time_sec`** | `FLOAT`         |      -      |       Yes       | 完賽時間 (秒)            | `70.12` (即 1:10.12)                      |
| **`margin_len`**      | `FLOAT`         |      -      |       Yes       | 勝負距離 (馬身數)        | `0.0` (頭馬), `0.25` (頸位), `1.5`        |
| **`rating`**          | `FLOAT`         |      -      |       Yes       | 出賽時評分               | `60.0`, `85.0`                            |

---

## 3. `race_sectionals` (分段時間與走位數據)

記錄馬匹在比賽過程中各分段的走位名次、分段時間與跟隨距離。


| 欄位名稱 (Column)        | 資料型態 (Type) |  外鍵 (FK)  | 允許空值 (Null) | 說明 (Description)      | 範例 / 備註                |
| :----------------------- | :-------------- | :----------: | :-------------: | :---------------------- | :------------------------- |
| **`race_id`**            | `TEXT`          | FK (`races`) |       No       | 對應賽事識別碼          | `2024-01-01_ST_1`          |
| **`horse_name`**         | `TEXT`          |      -      |       No       | 馬匹名稱                | `金槍六十`                 |
| **`horse_id`**           | `TEXT`          |      -      |       Yes       | 馬匹烙號 / 專屬代號     | `E123`                     |
| **`section_no`**         | `BIGINT`        |      -      |       No       | 第幾段分段 (1-based)    | `1`, `2`, `3`, `4`         |
| **`position`**           | `FLOAT`         |      -      |       Yes       | 該分段通過時的位置/名次 | `1.0` (領放), `5.0` (居中) |
| **`sectional_time_sec`** | `FLOAT`         |      -      |       Yes       | 該分段耗時 (秒)         | `22.88`, `23.15`           |
| **`margin_behind`**      | `FLOAT`         |      -      |       Yes       | 該分段落後頭馬/前馬距離 | `1-1/2` (字串格式馬身數)   |
